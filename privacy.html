Developer Studio – Privacy Policy

Last updated: November 22, 2026

Developer Studio is a personal tool that runs only on its owner's own computer. It is used only by its owner to publish their own videos to their own accounts.

What data it uses

When you connect an account (for example YouTube through Google Sign-In), Developer Studio receives an access token and reads your channel or account name, ID and profile picture. It uses this only to upload videos, set thumbnails, post comments and show which account is connected.

Where data is stored

Tokens and account details are stored encrypted on the owner's computer only. Nothing is sent to any server run by Developer Studio. Data goes only to the platform you publish to (Google/YouTube, Meta, TikTok).

Sharing

Developer Studio does not sell, share or transfer your data to anyone.

Google user data

Developer Studio's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

You can disconnect an account in Developer Studio's Settings, which deletes its stored tokens. You can also revoke access at any time at myaccount.google.com/permissions.
